# Branding name check — GW2 Waypoint Search rebrand

Checked 2026-11-17. No code changed, no DLL rebuilt.
Scope: Raidcore Nexus Addon Library (raidcore.gg/gw2/addons, first page + site: searches),
Blish HUD modules / module repo, GitHub, GW2 wiki / forums / Reddit, general web search.
Caveat: Raidcore's library is paginated (~96 addons per its Summer 2026 update) and its
in-site search is not exposed to a text fetch, so the check is: first-page listing +
site:raidcore.gg searches + general web searches for each exact name. No exact GW2-addon
match was found for any candidate. That is not a legal trademark clearance.

## Wayfinder — why AVOID, despite being the favourite name

No Guild Wars 2 addon called "Wayfinder" was found. The collision is not with another
addon — it is with GW2 itself, and with a standalone game:

1. **GW2 in-game "Wayfinder" is ArenaNet's own term, and it is getting more prominent,
   not less.**
   - The player character is called the Wayfinder in Secrets of the Obscure story.
   - "Wayfinder Mastery" — final tier of the Astral Ward mastery track, added
     21 May 2024 (The Midnight King). Sources: devtrackers.gg game-update notes
     21 May 2024; guide.guildwar.win SotO masteries page.
     https://devtrackers.gg/guild-wars-2/p/a3e4fa04-game-update-notes-may-21-2024
     https://guide.guildwar.win/en/progression/systems/masteries/secrets-of-the-obscure/
   - "Relic of the Wayfinder" — in-game relic.
   - **"Wayfinder's Portal Tome" — new in-game travel item, added 10 Nov 2026**
     (replaces / sits alongside the Wizard's Portal Tome; consolidates portal
     scrolls, season tomes and lounge passes into one item). Sources:
     GW2 forums, "Castora Entry for the Wizard's Portal Tome", 8–10 Nov 2026
     https://en-forum.guildwars2.com/topic/178283-castora-entry-for-the-wizards-portal-tome/
     Snow Crows, 11 Nov 2026, "New Lounge Pass Portal Tome and Wayfinder's Portal
     Tome: Everything You Need to Know" — https://snowcrows.com/
     that_shaman, 10 Nov 2026 patch notes — https://thatshaman.com/post/2026/11/10/543/Upcoming-features-from-the-November-10-patch
   - A user searching "Wayfinder GW2" will get the mastery / relic / portal tome
     first, not an addon. An addon named "Wayfinder" would be constantly confused
     with the official travel item — which is itself about finding/travelling to
     places, i.e. the same semantic space as this addon.
2. **"Wayfinder" is a registered trademark for a standalone game.**
   - WAYFINDER, Airship Syndicate Entertainment Inc., USPTO Serial 88648494,
     REGISTERED 2 May 2023, Reg. No. 7043342, Class 9 (downloadable game software)
     and Class 41 (online computer game). First use Dec 2022.
     https://furm.com/trademarks/wayfinder-88648494
     https://www.trademarkelite.com/trademark/trademark-detail/88648494/WAYFINDER
   - Canada: application 2258614, registration published 26 Dec 2025.
   - This is not legal advice and a small free GW2 addon is a different market
     from a standalone game, but "Wayfinder" alone is the single riskiest name
     on the list, and it is also the least distinctive in search.
3. **The word is reused everywhere else in gaming.**
   - "Wayfinder Classic" — WoW addon ("More than a waypoint addon…").
     https://wow.curseforge.com/ (CurseForge WoW addons listing, Aug 2026)
   - "Wayfinder" — Skyrim Special Edition mod, Kingdom Come: Deliverance mod,
     Valheim mod ("The Wayfinder"), Pathfinder 2e items, etc.
   - None of these is a GW2 addon, but they show the name carries no
     distinctiveness in search.

"Tyria Wayfinder" fixes the Airship Syndicate confusion (the "Tyria" prefix
disambiguates from the standalone game) but does **not** fix the GW2 in-game
confusion — "Wayfinder's Portal Tome" and "Wayfinder Mastery" are still the
first things a GW2 player thinks of. Verdict: risky / avoid.

## Tyria Finder — SAFE, recommended

- No exact match found in Raidcore, Blish, GitHub, GW2 wiki/forums, or general web
  search for "Tyria Finder" as a GW2 addon/tool.
- Near matches are functionally different and differently named:
  - Blish HUD "Item Search" — searches the player's bank/inventory, not the world.
    https://guide.guildwar.win/en/tools/addons/blishhud/
  - Raidcore "NexusGameWiki" — in-game wiki search, not a waypoint/POI finder.
    https://raidcore.gg/gw2/addons (first-page listing, 17 Nov 2026)
  - Blish HUD "Pathing" — marker/trail packs, no name search.
- "Finder" describes exactly what the addon does (search by name, get a chat code),
  and "Tyria" makes it unmistakably GW2. Short, searchable, distinctive in the
  GW2 addon space.

## Tyria Atlas — SAFE

- No exact match found for "Tyria Atlas" as a GW2 addon/tool.
- Near matches:
  - "Augmented Tyria" — old GW2 map-completion tool by ideka (2017-era, routes
    on the minimap). Different name, different function (routes, not search),
    and long discontinued — ideka's Ko-fi now lists Quill of the Mists / Racing
    Meter / Hitbox View, and says "Back in the day I made Augmented Tyria, too."
    https://ko-fi.com/ideka/
    https://www.gamersdecide.com/articles/best-gw2-addons
  - "Atlas" — generic: WoW "Atlas" (instance maps, forked), Minecraft
    "Wayfarer's Atlas", WoW "Gather Atlas" / "Drop Atlas". None is GW2, none is
    called "Tyria Atlas".
  - Blish HUD module list has no "Atlas" module (blishhud.com/modules/ returns
    only a Discord link in text fetch; module names checked via
    guide.guildwar.win Blish page: Pathing, Item Search, Inquest Chipset,
    KpRefresher, Mounts & More, Mouse Cursor).
- Caveat: "Atlas" implies a map/atlas, which fits the achievement-hunting
  direction, but says "map" more than "search". Still safe.

## Find It in Tyria — SAFE, weak

- No exact match found anywhere.
- Weak as a brand: long, phrase-like, hard to type/search, no obvious short form.
  Safe if Audrey loves the phrasing, but "Tyria Finder" says the same thing in
  two words.

## GW2 Waypoint Search (current) — SAFE, narrow

- No other GW2 addon with this exact name was found. Searches returned WoW
  addons only ("Waypoint UI", "Waypoint Tracker — Quest Arrow & NPC Finder",
  CurseForge/Wago), which are a different game.
- The problem is branding, not collision: it undersells the addon (POIs, vistas,
  JPs, adventures, mini dungeons, collections, PSNA, bosses, metas, gathering,
  services, regions). Safe to keep, but the rebrand is justified.

## Alternatives (verified not in use in the GW2 addon space)

Checked with the same searches as above; no GW2 addon/tool found for any of these:

1. **Tyria Compass** — no match. "Compass" is used by Blish's Compass module
   and by WoW "Compass" addons, but no "Tyria Compass" in GW2.
2. **Tyria Seeker** — no match.
3. **Tyria Locator** — no match.
4. **Where in Tyria** — no addon match; only a FunTrivia quiz ("Where Are We
   In Tyria?") and generic forum phrasing. Phrase-like, like "Find It in Tyria".
5. **GW2 Finder** — no addon match found; generic, and "Finder" alone is
   weaker than "Tyria Finder".

Recommendation order: **Tyria Finder** > Tyria Atlas > Tyria Compass >
Tyria Seeker > keep GW2 Waypoint Search. Avoid Wayfinder / Tyria Wayfinder.
